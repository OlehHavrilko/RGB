# Chromify

Приложение для управления RGB-лентой через BLE-контроллер **ELK-BLEDOM**.
Flutter, один код для Windows и Android. Первый этап — Windows.

## Возможности

- Поиск BLE-устройств и подключение, автопереподключение при разрыве
  (в т.ч. повтор при неудачном discovery).
- **Многодевайсность**: можно держать подключёнными несколько лент
  одновременно — экран «Устройства» показывает секцию «Мои устройства» с
  живым статусом каждой, у каждой своё состояние/таймер сна/расписание,
  библиотека пресетов общая на всё приложение.
- **Режим синхронизации**: значок в шапке экрана управления (виден, когда
  подключено больше одного устройства) — пока включён, изменение
  цвета/эффекта/яркости/питания на этой ленте зеркалится на все остальные
  подключённые.
- **Сцены**: значок в шапке экрана «Устройства» — «Сохранить текущее»
  снимает состояние (включая питание) всех подключённых сразу лент под
  одним именем; применяется одним нажатием и возвращает на разных лентах
  разные цвета/режимы одновременно.
- Включение / выключение ленты.
- Выбор цвета: HSV-круг + слайдеры R/G/B + быстрые цвета.
- Яркость (единый регистр контроллера, без двойного затемнения).
- Режим белого света (тёплый ↔ холодный).
- Встроенные эффекты + регулировка скорости.
- **Пользовательские пресеты**: сохранить текущий режим/цвет/яркость/эффект
  и применять одним нажатием. Экспорт/импорт пресетов через буфер обмена
  (кнопки над списком пресетов).
- **Запоминание последнего режима**: состояние ленты восстанавливается при
  следующем запуске.
- **Таймер сна**: одноразовое автоотключение через 15 мин … 2 ч
  (переживает перезапуск приложения).
- **Ежедневное расписание**: автоматическое включение/выключение по времени
  и дням недели (пока приложение запущено).
- **Будильник-рассвет**: вместо резкого включения на полную лента плавно
  набирает яркость от минимума до заданной цели за настраиваемое время
  (5–60 мин); настраивается на экране «Расписание».
- **Локализация (RU/EN)**: значок «RU»/«EN» в шапке экрана «Устройства»
  переключает язык всего интерфейса; по умолчанию берётся язык системы.
- **Виджет главного экрана (Android)**: показывает имя, статус подключения и
  индикатор питания активного устройства (предпочитается подключённое) и до
  двух пресетов; тап по индикатору питания включает/выключает ленту, тап по
  пресету применяет его — открывая приложение, которое сразу выполняет
  действие.
- Современный тёмный интерфейс: «стеклянные» карточки, живое свечение фона
  под текущий цвет, анимации переходов и нажатий.
- Иконка приложения и инсталлятор для Windows.

Отложено (нужна проверка на железе): микрофон/музыкальная реакция,
расписание на самом контроллере, локализация.

Планы по развитию — в [ROADMAP.md](../ROADMAP.md).

## Структура

```
lib/
  protocol/   кодек команд ELK-BLEDOM (чистый Dart, покрыт тестами)
  ble/        обёртка universal_ble: сканирование, соединение, запись
  state/      DeviceController / ScanController (provider + ChangeNotifier)
  ui/         тема, переиспользуемые виджеты, экраны scan/ и control/
test/
  protocol/   unit-тесты кодека и парсера статуса
```

## Сборка и запуск на Windows

BLE под Windows требует нативной сборки, поэтому её запускают **со стороны
Windows**, а не из WSL.

### Один раз

1. Установить **Visual Studio 2022** с рабочей нагрузкой
   **«Разработка классических приложений на C++» (Desktop development with C++)**.
2. Установить **Flutter SDK для Windows**
   (<https://docs.flutter.dev/get-started/install/windows>) и добавить
   `flutter\bin` в `PATH`.
3. Включить Bluetooth в системе (Параметры → Bluetooth и устройства).
4. Проверка окружения: `flutter doctor` — разделы **Windows** и
   **Visual Studio** должны быть отмечены галочкой.

### Запуск

В PowerShell или Windows Terminal:

```powershell
cd \\wsl.localhost\Ubuntu-24.04\home\oleh\work\RGB\app
flutter config --enable-windows-desktop
flutter pub get
flutter run -d windows
```

Сборка релизного `.exe`:

```powershell
flutter build windows --release
# результат: build\windows\x64\runner\Release\
```

> Проект лежит в файловой системе WSL. Обычно всё работает по пути
> `\\wsl.localhost\...`, но hot reload по сети иногда пропускает изменения —
> тогда нажмите `R` (hot restart) в консоли `flutter run`. Если будут
> странности со сборкой — скопируйте папку `app` на диск `C:` и соберите
> оттуда.

## Инсталлятор (Chromify-Setup-x64.exe)

### Через GitHub Actions (без Windows-машины)

Workflow `.github/workflows/windows-installer.yml` собирает релиз и
компилирует инсталлятор на раннере `windows-latest`.

- вручную: вкладка **Actions → Windows installer → Run workflow**;
- по тегу: `git tag v1.0.0 && git push --tags` — инсталлятор дополнительно
  прикрепляется к GitHub Release.

Готовый `Chromify-Setup-x64.exe` лежит в артефактах прогона.

### Локально на Windows

Нужны Flutter (Windows), Visual Studio 2022 (Desktop C++) и
[Inno Setup 6](https://jrsoftware.org/isdl.php). Затем из корня репозитория:

```powershell
.\scripts\build_windows.ps1
# результат: dist\Chromify-Setup-x64.exe
```

Инсталлятор ставит приложение per-user (без прав администратора),
создаёт ярлыки и пункт в «Установка и удаление программ».
Иконка приложения генерируется из `app/assets/icon/app_icon.png`
(скрипт-генератор — `tools/gen_icon.py`).

## Как пользоваться

1. Запитать контроллер, включить Bluetooth.
2. Открыть приложение — начнётся поиск. Контроллер появится как
   **ELK-BLEDOM** с пометкой «поддерживается».
3. Нажать на него — откроется экран управления и произойдёт подключение.
4. Кнопка-«шар» — питание. Ниже — режимы: Цвет / Белый / Эффекты и яркость.
5. **Пресеты** — кнопка «Сохранить» над яркостью; тап по чипу применяет,
   долгое нажатие удаляет.
6. **Таймер сна** — внизу экрана управления.
7. **Расписание** — иконка часов в шапке экрана управления.

## Протокол ELK-BLEDOM (кратко)

- Сервис `0000fff0-…`, характеристика записи `0000fff3-…`, write without response.
- Кадр 9 байт: `7E 00 <cmd> <p1..p4> 00 EF`.
- Питание вкл: `7E 00 04 F0 00 01 FF 00 EF`, выкл: `7E 00 04 00 00 00 FF 00 EF`.
- Цвет: `7E 00 05 03 RR GG BB 00 EF`; яркость: `7E 00 01 XX 00 00 00 00 EF`.
- Белый: `7E 00 05 02 <тёплый> <холодный> 00 00 EF` (сумма = 100).
- Эффект: `7E 00 03 <id> 03 00 00 00 EF`; скорость: `7E 00 02 SS 00 00 00 00 EF`.

Полная таблица и подписи эффектов — в `lib/protocol/`.
